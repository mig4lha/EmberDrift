## Building EmberDrift (macOS + Xcode)

This repo is set up to generate an Xcode project via **XcodeGen**.

### Generate the Xcode project
- Install XcodeGen (one-time):

```bash
brew install xcodegen
```

- From the repo root:

```bash
xcodegen
open EmberDrift.xcodeproj
```

### Run
- Select an iOS Simulator (or device) and press Run.
